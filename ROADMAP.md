# 🗺️ Roadmap

The repository is built **top-down**: leadership and governance first, then assurance, privacy, architecture, engineering, operations, defensive depth, offensive depth, and specialized cyber-physical domains.

## Release philosophy

1. **Structure first.**
2. **One field guide at a time.**
3. **Depth before volume.**
4. **Primary and authoritative sources before secondary summaries.**
5. **Practical resources accompany theory.**
6. **Every guide remains maintainable and versioned.**

## Initial publication sequence

1. CMS-FG-001 — CISO Leadership
2. Cybersecurity Program Management
3. Information Security Governance
4. GRC Practitioner
5. Cyber Risk Management
6. Security Controls
7. Audit & Assurance
8. Privacy & Data Protection
9. Security Architecture
10. Cloud Security
11. SOC Operations
12. Incident Response
13. Detection Engineering
14. Threat Hunting
15. DFIR
16. Vulnerability Research
17. Malware Analysis
18. Reverse Engineering
19. OT / ICS / IACS
20. Specialized cyber-physical and emerging technology tracks

The roadmap is intentionally open-ended. New domains can be added without breaking the core architecture.
