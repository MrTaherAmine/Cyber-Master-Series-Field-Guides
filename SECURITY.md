# Security Policy

## Reporting a repository security issue

If you discover a security issue in code, workflows, examples, or repository automation, report it privately to the maintainer through the contact channels listed at https://www.taheramine.org.

Do not include live secrets, stolen data, or third-party confidential information.

## Scope

This repository is primarily educational content. Some future labs may include intentionally vulnerable or dual-use material. Such content must be clearly marked and designed for authorized environments.
