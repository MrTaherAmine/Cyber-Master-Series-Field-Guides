# Code of Conduct

We expect respectful, professional, evidence-based collaboration.

Harassment, discrimination, doxxing, threats, credential theft, malicious code submissions, or attempts to use the project community for unauthorized activity are not acceptable.

Technical disagreement is welcome. Personal attacks are not.

Project moderation decisions are made to protect the quality, safety, and professional purpose of the repository.
